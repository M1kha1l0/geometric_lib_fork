## Решение 
Были созданы 2 файла с функциями вычисления периметра и площади квадрата и окружности.
В решении были используются формулы
Периметра:
- $P = 4 * a$ - квадрата.
- $P = 2\pi r$ - окружности.
Площади:
- $S = a^2$ - квадрата.
- $P = \pi r^2$ - окружности.

## Описание функций
### circle.py
Пример использования
```python
import math  

def area(r):
'''
Функция вычисления площади окружности
	На вход подается число>0 r - радиус окружности
	На выходе получаем число вычисляемое по формуле площади окружности
Используем числовую константу из библиотеки math
'''

return math.pi * r * r

def perimeter(r):
'''
Функция вычисления периметра
	На вход подается число>0 r - радиус окружности
	На выходе получаем число вычисляемое по формуле периметра окружности
Используем числовую константу из библиотеки math
'''

return 2 * math.pi * r

print(area(4))      # вывод: 50.26548245743669
print(perimeter(4)) # вывод: 25.132741228718345
print(area(6))      # вывод: 113.09733552923255
print(perimeter(6)) # вывод: 37.69911184307752
```

### square.py
Пример использования
```python
def area(a):
'''
Функция вычисления площади квадрата
	На вход подается число a>0 - сторона квадрата
	На выходе получаем квадрат числа а - площадь квадрата со стороной а
'''

return a * a

def perimeter(a):
'''
Функция вычисления периметра квадрата
	На вход подается число a>0 - сторона квадрата
	На выходе получаем 4 умноженное на а - периметр квадрата со стороной а
'''

return 4 * a

print(area(10))      # вывод: 100
print(perimeter(10)) # вывод: 40
print(area(20))      # вывод: 400
print(perimeter(20)) # вывод: 80
```
